Fonts are bundled/traced server-side; the renderer makes no remote font requests.
Missing glyph coverage fails closed rather than silently replacing customer text.
Latin/Devanagari are covered; other scripts require reviewed licensed fonts and
layout tests before use. These fonts do not establish invoice tax compliance.
