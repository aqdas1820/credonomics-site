# Motion guidelines

- Hover/focus feedback: 180ms. Card rise: 2px, fine pointers only. Button press: scale .99.
- Search: native modal dialog, 220ms visual entry. Native background inertness/focus containment; Escape and focus restoration; combobox/results semantics and arrow selection.
- Section entry: 420ms, translate 12px, observed once; all content remains visible without JavaScript. Observer cleanup on route change; new data-loaded sections are observed without logging their contents.
- Hero: static first-paint heading, 650–900ms finite transforms/connector reveal. No pointer tracking, infinite orbit, ticker or marquee. Decorative network explicitly describes a conceptual framework.
- Internal contextual accents describe workflows, not live data states or fabricated holdings/weights. Legal/company pages stay editorial; account, watchlist and alerts have no added entry scene.
- Reduced motion disables animations and transitions within the shared experience. No extra animation library, canvas, video or WebGL dependency.
- Financial values update from existing calculations and backend responses; no number interpolation, delayed calculations or optimistic payment status was added.
