CREDONOMICS — GOOGLE SEARCH CONSOLE SETUP
=========================================

1. Add https://www.credonomics.in in Google Search Console.
2. Use the HTML tag verification method if you want to use the built-in Vercel environment-variable route.
3. Copy only Google's verification token.
4. In Vercel > Project > Settings > Environment Variables add:
   NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=<your-token>
5. Redeploy Production.
6. Verify ownership in Search Console.
7. Submit https://www.credonomics.in/sitemap.xml
8. Inspect the homepage, the three primary calculators and the four focused calculators.

Never invent a verification token. It must come from the site owner's Google Search Console property.
